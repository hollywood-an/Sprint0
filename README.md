## What it Does

I created with Monogame a small adventure where a hooded adventure sprite moves around the screen with the normal WASD and has an animated walk with it. The sprite also has an ability to dash and move to certain locations within the screen with a left mouse click and the ability to stop with the right mouse click. The dash effect dashes in the direction the sprite is facing and has a cooldown. The character moves around the screen and is unable to leave the borders and you can quit anytime you want with the Q or escape key.

## Controls

W - Move Up
A - Move Left
S - Move Down
D - Move Right
Space - Dash in the Direction of Movement
Left Click - Walk to spot on screen clicked on
Right Click - Stop moving
Q/esc - Quit the Game

## How I Used AI

In this project, I used AI to generate the original character spritesheet with Claude and it generated a python script in Tools which writes out the Content/adventurer.png. I wrote the code and plan and whenever I needed help with code I would talk to Claude Code and have it guide me through how to fix any issues. The character's movement and animation logic was made by myself for this assignment and not taken from MonoGame or an open-source.
